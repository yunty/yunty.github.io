# 클론해오기
```Bash
git clone http주소 폴더명
ex) git clone https://github.com/yunty/java-christmas-6-study.git christmas-study
```

# 브랜치 생성
```Bash
git swith -c 브랜치명
git push -u origin 브랜치명 // 이거 해줘야지 브랜치 반영됨
// -u origin을 통해 이후에는 브랜치명을 안치고 git push만 해도 자동으로 커밋이 해당 브랜치로 푸쉬됨
```
