## 세부 내용
### 객체지향적으로 생각하기
- SOLID
- 객체에 대한 책임
### 복사 붙여넣기
- 한 줄 복사 : Command + D
- 한 줄 잘라내기 : Command + X
- 줄 위/아래 이동 : Option + Shift + ↑ / ↓
### 검색 이동
- 프로젝트 전체 찾기 Command + Shift + F
- 파일 구조(메서드 목록) Command + F12
### 코드 수정
- 선택영역 감싸기 : Command + Option + T
- 변수로 추출 : Command + Option + V
- 메서드 추출 : Command + Option + M
- 필드 추출 : Command + Option + F
- 상수 추출 : Command + Option + C
- 인라인 : Command + Option + N
- 리팩토링 메뉴 : Control + T
### 창, 도구 관리
- 탭 이동 : Command + Shift + [ / ]
- 프로젝트 창 열기/닫기 : Command + 1
- 폴더 펼치기/접기 : → / ←
- 새로 만들기 : Command + N
