# Facade
#### 퍼사드 패턴
사전적 의미 : 건물 외벽, 창구

---
## 개념
복잡하게 많이 작성되어있는 여러 클래스 혹은 라이브러리를 사용자가 손 쉽게 사용할 수 있게 인터페이스를 구성해주는 기법

---
## 장·단점
#### 장점
- 외부에서 시스템을 사용하기 쉬워진다.
- 의존성을 한 곳으로 모을 수 있음
- 사용자가 다른 복잡한 클래스는 몰라도 되고 파사드 클래스만 이해하고 사용하면 됨

#### 단점
- 모든 클래스를 다 한곳으로 모으면 God 객체(과도한 책임)이 된다 즉 SRP를 위반하는 행위임 
---
## 사용 방법
### 우리가 평소 run 메서드를 구성하면서 여러 객체들을 불러오고 순서에 맞춰서 우리가 조합해둔것이 파사드 패턴이다. 즉 상대는 run만 실행시키면 내부는 몰라도 진행이 된다.
