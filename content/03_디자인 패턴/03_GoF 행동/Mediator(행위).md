# Mediator
중재자 패턴
#### 
객체들이 서로 직접 호출하지 않고 중재자에게 요청하면 중재자가 알맞은 객체를 전달하고 전체 협업을 조정하는 패턴이다.

---
## 개념

#### 구조
- Mediator : 중재자 인터페이스
- Colleague : 중재자를 사용할 친구들의 인터페이스(서로 다른 책임이면 필요없음)
- ConcreteColleague : 중재자를 사용해서 서로 소통할 객체들
- ConcreteMediator : 소통해야하는 객체들을 합성을 통해 중재시켜주는 객체

## 사용 방법 
다른 객체들끼리는 중재자만을 통해 소통하고
