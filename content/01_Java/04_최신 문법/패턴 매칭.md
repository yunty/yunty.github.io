# 패턴 매칭
- 타입 검사 + 캐스팅 + 변수 선언을 **한 번에** 하는 문법 (자바 16~21)
- 필요한 곳 : `Object`, 인터페이스처럼 **상위 타입으로 받은 값**을 특정 타입일 때만 쓰고 싶을 때
- 겉 타입(Object)과 실제 타입(Point)이 다르니까 검사가 필요한 것

```java
// 기존
if (obj instanceof Point) { Point p = (Point) obj; }

// 패턴 매칭
if (obj instanceof Point p) { p.x(); }
if (obj instanceof Point(int x, int y)) { }  // 레코드 패턴, 안의 값까지 꺼냄
```
- 타입이 정해진 값은 getter로 충분. 중첩 레코드나 switch에서 이득이 큼
