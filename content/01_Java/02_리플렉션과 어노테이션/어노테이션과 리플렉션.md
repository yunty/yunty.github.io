# 어노테이션과 리플렉션
- 어노테이션 : 코드에 붙이는 꼬리표. **스스로는 아무 동작도 안 함**
- 읽어서 처리하는 쪽(컴파일러, Lombok, 스프링)이 있어야 효과가 생김
- 어디까지 남을지는 `@Retention`으로 정함 (어노테이션 만든 쪽이 결정)

| Retention | 남는 범위 | 읽는 쪽 |
|---|---|---|
| SOURCE | 소스까지 | 컴파일러(`@Override`), Lombok |
| CLASS | .class까지 | 거의 안 씀 (기본값) |
| RUNTIME | 실행 중까지 | 스프링 (리플렉션, 바이트코드) |

- 리플렉션 : 실행 중에 이 꼬리표를 읽는 방법 중 하나 → [[리플렉션_Reflection]]
- 직접 만들 땐 `@interface`, 읽는 코드는 따로 짜야 함

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
@interface LogTime { String value() default ""; }

LogTime a = method.getAnnotation(LogTime.class); // 꼬리표 읽기
```
