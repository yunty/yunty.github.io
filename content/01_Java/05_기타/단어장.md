# IDE
---
**Intergrated Development Environment &rarr; 통합 개발 환경**
- Java로 작성된 Java기반 애플리케이션
- JDK를 이용하여 컴파일을 도와줌
- 문법, 코드 편집기, 자동완성 등 편의 기능을 제공

# JDK 
---
**Java Development Kit &rarr; 자바 개발 도구**
- JRE, JVM, JAVAC
- 자바 프로그램 개발 목적

# JRE
---
**Java Runtime Enviroment &rarr; 자바 실행 환경**
- JVM + 표준 라이브러리
- 자바 프로그램 실행 목적
# JVM
---
**Java Virtual Muchine**
- .class &rarr; CPU 바이트 코드
- 자바 프로그램을 실행하는 가상 머신
- 바이트코드 실행 목적
- JVM 인터프리터 + JIT + 메모리 할당 받은것들
# JAVAC
---
**Java 컴파일러**
-.java &rarr; .class

# Abstract Class
---
**추상클래스**
- 하나 이상의 추상메서드가 있으면 무조건 클래스를 추상 클래스로 해야함
- 인스턴스 생성 불가

# Concrete Class
---
**구상클래스**
- new 연산자를 사용하여 인스턴스를 생성할 수 있는 클래스를 Concrete 클래스라고 한다.
- 추상 클래스에 정의된 기능을 구현하는 클래스이다.

# 깊은복사
- 새로운 객체를 생성하여 내 값을 하나하나 값만 복사하는것 참조값 복사가 아닌
- 그냥 참조변수를 반환하면 사이드 이팩트 발생 위험 &rarr; 새 객체에 넣어서 반환

# 얇은복사
- 그냥 참조값 그대로 넘겨주는거
- 사이드 이팩트 발생
