# 정규표현식
- *: 0개 이상 / + : 1개 이상 / ? : 0개 또는 1개
- ^ : 문자열 시작 / $ : 문자열 끝 / [^ ]안에 들어가면 not을 의미 / [^a-z] 소문자를 제외한 모든 문자
-  [] 범위 지정 / [a-z] 소문자만 / [가-힣] 한글만 / [a-z가-힣] 소문자랑 한글만
- { } 갯수 지정 / \b{4} 숫자 4자리 \b{2,4} 숫자 2~4자리
- ( ) 반복 지정 + 그룹지정 / (ab) ab가 반복되어야 함 ex) abab / (?:...)반복 하되 그룹 x
- . : 아무 문자 1개 / 
- \d : 숫자 | \D : 숫자를 제외한 | \w : 영문, 숫자, _ 만 | \W 영문, 숫자, _를 제외
- \s : 공백 문자 | \S : 공백이 아닌 문자
- 문자열에서 \를 표현하려면 \\ 2번써야함 -> \\s = \s
- !!! 중요 !!! \는 문자 그 자체를 의미 -> \+ 는 "+" 1개를 의미
- !!! 중요 !!! \는 자바 문자열에서 나타내려면 \\로 2개로 해야 \가 나옴

```java
String.matches(regex) 문자열이 정규식에 맞는지
Pattern pattern = Pattern.compile("\\d+"); // 패턴 지정
Matcher matcher = pattern.matcher("abc123def456"); //일치하는지 -> matcher.matches()
```
```
Greedy : .* : 최대한 많이 | Lazy : .*? : 최소한만
Lookahead : (?=...) -> \\d+(?=원) -> 1000원을 넣으면 1000만 찾음
Lookbehind : (?<=...) -> (?<=$)\\d+ -> $1000 을 넣으면 1000만 찾음
```
